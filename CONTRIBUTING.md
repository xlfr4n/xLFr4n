# ⚡ Contributing to xLFr4n // LAB

> **xLFr4n repository standard · ES + EN**

## 🇪🇸 Español

Este repositorio forma parte del ecosistema técnico de **xLFr4n**. Las contribuciones deben priorizar claridad, trazabilidad y cambios que puedan comprobarse.

### Antes de cambiar

- Lee `README.md` y `BRAND.md`.
- Comprueba cómo encaja el cambio con la estructura existente.
- No incluyas secretos, credenciales, cookies, tokens ni datos privados.
- Conserva la documentación bilingüe cuando el archivo ya siga ese formato.

### Calidad

- Explica el **porqué** cuando el cambio no sea obvio.
- Mantén los cambios pequeños y coherentes con el proyecto.
- Añade o actualiza pruebas cuando exista una superficie testeable.
- Verifica localmente lo que puedas antes de abrir una propuesta.
- No fabriques métricas, resultados, estado operativo ni evidencia.

### Pull requests

Describe:
1. qué cambia;
2. por qué cambia;
3. cómo se comprobó;
4. qué queda deliberadamente fuera.

**Firma de proyecto:** ⚡ xLFr4n

## 🇬🇧 English

This repository is part of the **xLFr4n** technical ecosystem. Contributions should favor clarity, traceability and changes that can be verified.

Before changing anything, read `README.md` and `BRAND.md`, understand the existing structure, and keep secrets and private data out of Git.

Prefer focused changes, explain non-obvious decisions, add/update tests where practical, and never invent metrics, results, operational status or evidence.

Pull requests should explain what changed, why, how it was verified, and what intentionally remains outside the scope.

**Project signature:** ⚡ xLFr4n
