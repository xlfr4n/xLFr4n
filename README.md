## 🧪 METHOD

<details>
<summary><strong>01 → INVESTIGATE</strong></summary>

Inspect the actual system first. Define the problem, identify boundaries and separate facts from assumptions.

</details>

<details>
<summary><strong>02 → BUILD</strong></summary>

Create the smallest useful implementation that can prove the idea and leave room for iteration.

</details>

<details>
<summary><strong>03 → VERIFY</strong></summary>

Test the result that actually exists. Prefer reproducible checks over claims based on intention or appearance.

</details>

<details>
<summary><strong>04 → AUTOMATE</strong></summary>

Convert repeated work into scripts, workflows and dependable developer tooling.

</details>

<details>
<summary><strong>05 → DOCUMENT</strong></summary>

Record what was changed, why it changed and what can be checked later.

</details>
