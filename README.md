## 🧪 Método / Method

<div align="center">

<img src="https://capsule-render.vercel.app/api?type=rect&height=62&text=INVESTIGATE%20%20%E2%86%92%20%20BUILD%20%20%E2%86%92%20%20VERIFY%20%20%E2%86%92%20%20AUTOMATE&fontSize=17&fontColor=F5F7FA&color=06080C&stroke=FF3344&strokeWidth=1&animation=twinkling" alt="xLFr4n engineering loop">

</div>

| Stage | 🇪🇸 Español | 🇺🇸 English |
|---|---|---|
| **01 🔎** | Entender el problema y el contexto | Understand the problem and context |
| **02 🛠️** | Construir lo necesario, sin sobrecomplicar | Build what is needed without overcomplicating |
| **03 ✅** | Probar lo que se ha cambiado | Test what has actually changed |
| **04 ⚙️** | Automatizar lo repetitivo | Automate repetitive work |
| **05 📚** | Documentar para que otro pueda seguirlo | Document it so someone else can follow it |

> 🇪🇸 **Evidencia > suposiciones.**  
> 🇺🇸 **Evidence > assumptions.**

> 🇪🇸 No presento como implementado lo que solo está planeado.  
> 🇺🇸 I do not present planned work as implemented work.
