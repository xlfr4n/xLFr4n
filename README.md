## Cómo trabajo

- **Primero entender.** Revisar el contexto y el comportamiento actual antes de tocarlo.
- **Cambios con intención.** Evitar rehacer lo que ya funciona y reducir efectos secundarios.
- **Verificar el resultado.** Probar los casos relevantes y no confundir una comprobación parcial con una garantía.
- **Documentar lo útil.** Dejar instrucciones reproducibles, límites conocidos y decisiones importantes.
- **Datos sin inventar.** Diferenciar hechos, estimaciones e hipótesis.
