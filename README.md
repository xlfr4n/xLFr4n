## Perfil

Soy **xLFr4n**, desarrollador independiente y aprendiz constante. Trabajo en proyectos que mezclan sistemas Linux, desarrollo web, seguridad, OSINT y automatización.

Suelo empezar por el problema, no por la herramienta. Después pruebo, comparo resultados y documento lo necesario para que el trabajo se pueda revisar y continuar. Me importa que un proyecto no solo tenga buena presencia: también debe ser entendible, útil y honesto con lo que realmente hace.

## Cómo trabajo

- **Entender antes de cambiar.** Revisar el contexto y el comportamiento actual.
- **Verificar antes de dar algo por hecho.** Probar los casos importantes y conservar evidencia útil.
- **Respetar lo que ya funciona.** Evitar cambios innecesarios y preferir mejoras pequeñas que se puedan revisar.
- **Documentar para la siguiente persona.** Instrucciones claras, límites conocidos y pasos reproducibles.

## About

I'm **xLFr4n**, an independent developer focused on Linux, web development, cybersecurity, OSINT and automation. I enjoy understanding why something fails as much as building something new. My approach is practical: investigate the problem, test the change, check the result and document what matters.

## Public work

- [xLFr4n-OSINT](https://github.com/xlfr4n/xLFr4n-OSINT) — public-source research tooling with provider controls, evidence provenance and reproducible reports.
- [Kali BSPWM](https://github.com/xlfr4n/xLFr4n-Kali-BSPWM) — a personal Kali Linux desktop setup with automation and lab documentation.
- [Habbo Furni Radar](https://github.com/xlfr4n/xLFr4n-Habbo-Furni-Radar) — new Collectibles detection and Discord alerts based on public sources.
- [MICRODOOM](https://xlfr4n.github.io/xLFr4n/play/) — a browser game experiment.
- [Web lab](https://xlfr4n.github.io/xLFr4n/) — a home for public projects and experiments.

## Private projects in development

- **xLFr4n-DevsAI / FMCP Labs:** a web platform bringing together digital tools, AI-assisted features, user areas and integrations. [Public website](https://fmcplabs.com/).
- **xLFr4n-Habbo-Portfolio:** desktop portfolio tooling for Habbo Collectibles, with history and explicit data-confidence states.
- **xLFr4n-Desencryp / AegisPot:** a documented lab layer around T-Pot CE that keeps upstream source separate from project automation.

I value maintainable work, clear boundaries and claims that can be checked against the actual implementation.
